# 人力资源 · 工资薪金个税测算

**形态**：测算型 ｜ **复现等级**：L3（纯确定性，无 LLM）｜ **行业**：人力资源 / 财税

## 规则来源

中国《个人所得税法》居民个人综合所得**累计预扣法**，7 级超额累进预扣率表：

| 累计应纳税所得额 | 预扣率 | 速算扣除数 |
|---|---|---|
| ≤ 36,000 | 3% | 0 |
| 36,000 ~ 144,000 | 10% | 2,520 |
| 144,000 ~ 300,000 | 20% | 16,920 |
| 300,000 ~ 420,000 | 25% | 31,920 |
| 420,000 ~ 660,000 | 30% | 52,920 |
| 660,000 ~ 960,000 | 35% | 85,920 |
| > 960,000 | 45% | 181,920 |

基本减除费用 5,000 元/月。

```text
累计应纳税所得额 = 累计收入 - 5000×月数 - 累计专项扣除 - 累计专项附加扣除
本期应预扣       = 累计应纳税额 - 累计已预扣
```
